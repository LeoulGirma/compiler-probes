Same code, three compilers, six different bets.

Five tiny functions, written the same way in Rust, Go and C#, plus build time. Every number is measured, and every cell opens the machine code the compiler actually produced. Each language wins somewhere, and the code shows why.

Run it on your machine

The harness needs Python 3 and the toolchains, nothing else. It writes results.json; load that file above to see your numbers in this page.

rustup toolchain install 1.99.0
dotnet --list-sdks                 # install .NET 10 and the .NET 11 RC SDKs
python3 probe.py --rust 1.99.0 --go go1.27.2 --dotnet 10
python3 probe.py --only cs --dotnet 11     # adds a .NET 11 column
python3 probe.py --only cs --dotnet 10 --aot   # adds ReadyToRun and NativeAOT builds

Defaults are what you get out of the box: rustc -C opt-level=3 (cargo --release), go build, C# Release on default runtime settings. Differences under 1.5× are treated as noise and labelled ≈.
