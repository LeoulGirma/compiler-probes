Microsoft's claims, measured

Medians of three rounds. The machine code column is what the compiler actually emitted, read straight from the JIT or the assembler output.

Startup: ReadyToRun's precompiled comparers

Checked on a second machine

The .NET 10 and .NET 11 JIT columns were rerun on a different CPU and OS: a 4-vCPU cloud server (Intel Haswell, Ubuntu Linux), five rounds with alternating order and its other workloads paused. .NET 11 against .NET 10, median of rounds. The server rounds used the release candidate (RC2); on the laptop, 11.0.0 matched RC2 within a few percent on every claim.

Every result holds. The devirtualisation wins are larger on the older server, runtime async cuts the cost of an await on both, and the Math.BigMul probe loop is slower on both: the stack round-trip in that loop costs more on Haswell, not less. Absolute times are not comparable between the two machines and are not shown.
